# 🍽️ Listagem de Restaurantes

Projeto em **Python** para cadastrar e listar restaurantes direto pelo terminal.

Fiz esse projeto pra praticar a lógica de programação e a organização de código em Python, saindo de exercícios soltos e montando algo com começo, meio e fim.

---

## 💡 Sobre o projeto

O usuário cadastra restaurantes com nome e categoria, ativa ou desativa cada um e vê a lista completa.

## ⚙️ Funcionalidades

- [ ] Cadastrar restaurante
- [ ] Listar restaurantes
- [ ] [Ativar / desativar restaurante]
- [ ] [outra funcionalidade]

## 🛠️ Tecnologias

- Python 3

## 🚀 Como rodar

```bash
# clone o repositório
git clone https://github.com/guilhermehtavares/Listagem-de-Restaurantes.git

# entre na pasta do projeto
cd Listagem-de-Restaurantes/listagem-restaurante

# rode o programa
python [nome-do-arquivo].py
```
> Precisa ter o Python 3 instalado na máquina.
